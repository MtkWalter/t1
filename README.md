# 寓所 · 3D 空間漫遊

依使用者提供的住宅電氣平面圖製作的互動 3D 示意模型。室內以 7.55 × 6.90 公尺為參考，陽台寬 1.20 公尺；牆高 2.70 公尺。門窗、家具及插座位置為估算，非施工或電氣設計依據。

## 啟動

在此目錄執行 `python3 -m http.server 8000 --bind 0.0.0.0`，使用瀏覽器開啟伺服器的 8000 連接埠。需支援 WebGL 的瀏覽器。Three.js 已存於 vendor，3D 執行不需外部 CDN。字型下載失敗時使用系統字型。

## 操作

- 點擊「進入空間漫遊」從大門旁的玄關開始。
- WASD 或方向鍵：前後左右移動，支援牆壁及家具碰撞。
- 按住滑鼠拖曳：轉動視線。雙擊場景鎖定滑鼠，Esc 釋放。
- 俯視總覽：拖曳旋轉、滾輪縮放。
- 右下角小地圖顯示目前位置與朝向。
- 可切換插座顯示、重設位置。

位置校正：原模型左下方冰箱處改為大門，冰箱移至餐桌旁方柱的右側；洗衣機設於陽台靠近主臥室的一端，取代該處盆栽。

餐桌靠外牆處依原圖補上方柱，示意尺寸為 0.75 × 0.70 公尺，柱高 2.70 公尺；已加入行走碰撞，尺寸仍需現場確認。

臥室配置：靠廚房的臥室為單人床（示意 1.00 × 1.90 公尺）；主臥室為雙人床（示意 1.50 × 1.90 公尺）及側牆衣櫥。已移除所有樹木與盆栽。

冷氣配置：主臥與次臥各一台壁掛室內機；兩台室外機示意為上下排列，裝於陽台靠主臥室的牆上。餐桌保留兩張椅子。

廚房沿牆由大門端往臥室端依序為洗手槽、備餐平台、雙口爐台；檯面與大門門框之間保留約 10 公分的示意間隙。
