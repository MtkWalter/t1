# 寓所 · 3D 空間漫遊

依使用者提供的住宅電氣平面圖製作的互動 3D 示意模型。室內以 7.55 × 6.90 公尺為參考，陽台寬 1.20 公尺；牆高 2.70 公尺。門窗、家具及插座位置為估算，非施工或電氣設計依據。

## 啟動

在此目錄執行 `python3 -m http.server 8000 --bind 0.0.0.0`，使用瀏覽器開啟伺服器的 8000 連接埠。需支援 WebGL 的瀏覽器。Three.js 已存於 vendor，3D 執行不需外部 CDN。字型下載失敗時使用系統字型。

## 操作

- 點擊「進入空間漫遊」從大門旁的玄關開始。
- WASD 或方向鍵：前後左右移動，支援牆壁及家具碰撞。
- 按住滑鼠拖曳：轉動視線。雙擊場景鎖定滑鼠，Esc 釋放。
- 俯視總覽：拖曳旋轉、滾輪縮放。
- 右下角小地圖顯示目前位置與朝向。
- 可切換插座顯示、重設位置。
